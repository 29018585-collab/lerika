# ЛериКа — кабинет и лаборатории V5.23 (development)

Рабочее приложение: https://lerika-cabinet.onrender.com/showroom/ ; кабинет администратора: /cabinet/ ; /health — проверка сервиса.
Render Free + отдельная база PostgreSQL Neon. Рабочая ветка lerika-cabinet-v1. Не использовать базы или сервисы других проектов.

## Настройка
- DATABASE_URL — TLS URI выделенной базы, SESSION_SECRET — случайный секрет от 32 символов, ADMIN_PASSWORD_HASH — хеш Werkzeug (scrypt/pbkdf2). Допускается ADMIN_PASSWORD в защищённых настройках Render, минимум 14 символов. Секреты не коммитить.
- На Render PostgreSQL обязателен. Локальный SQLite используется для тестов. Перед релизом проверять резервную копию и возможность восстановления.
- HTTPS; Secure, HttpOnly, SameSite Strict; CSRF для административных записей; лимиты входа и заявок разделены по отправителю.
- Вложения по умолчанию закрыты. Публикация заявок запрещена сервером. Только явно одобренные фотографии опубликованных проектов доступны публично.
- Ограничение хранения вложений — 350 МиБ суммарно, до 12 МиБ на заявку. Проверять лимиты Neon; бесплатный Render может засыпать.

## Проверки и публикация
- Изолированная ветка и PR; CI на SQLite и PostgreSQL, Chromium, инженерные регрессии, CAD-парсер, планировщик и тесты геометрии.
- python -m unittest -v test_design_studio (в cabinet); node --check static/admin.js; node --check ../portfolio-api.js.
- После зелёного CI — merge, проверить точный SHA активного deployment и выполнить GET smoke. Автодеплой Render включён, но при подтверждённом отсутствии нового deployment требуется ручной запуск. Не запускать повторные deploy параллельно.
- Тесты только на синтетических данных. Платные тарифы не подключать без согласования.
